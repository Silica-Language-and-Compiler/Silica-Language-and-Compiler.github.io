# Silica-Language-and-Compiler.github.io

The organization website, served from the root of
<https://silica-language-and-compiler.github.io/>.

It is a Jekyll site built by GitHub Pages. Its look follows the
[Silica documentation site](https://silica-language-and-compiler.github.io/silica/)
(`docs/` in the [silica](https://github.com/Silica-Language-and-Compiler/silica)
repository): `assets/css/silica.css` and `assets/js/site.js` are copies of that
site's files, so a design change there should be copied here too.

## Preview locally

    gem install jekyll
    jekyll serve

Then open <http://127.0.0.1:4000/>.
